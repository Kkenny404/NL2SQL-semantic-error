## 📋 Error Specification
**Error Category:** Function-related Errors
**Category Description:** Function-related Errors occur when NL2SQL models fail to correctly use SQL functions or misunderstand their purposes. We consider the following cases. CRITICAL: Function-related Errors focus on MISUSING the functions themselves, NOT on missing or incorrect clauses. Do not confuse with Clause-related Errors. Function-related Errors (CORRECT focus): Using wrong function types: SUM() instead of COUNT(), MAX() instead of MIN(); Incorrect function parameters: ROUND(value, -1) instead of ROUND(value, 2); Wrong function arguments: SUBSTR(text, 0, 5) instead of SUBSTR(text, 1, 5); Inappropriate function application: UPPER() on numeric data, mathematical functions on text; Function syntax errors: CAST(value, INT) instead of CAST(value AS INT). Clause-related Errors (AVOID - this is a different error category): Missing GROUP BY, ORDER BY, or HAVING clauses; Incorrect clause positioning or structure; Omitting necessary clauses that work with functions. Examples: ✅ CORRECT Function-related Error: Original: SELECT region, SUM(sales) FROM data GROUP BY region; Modified: SELECT region, COUNT(sales) FROM data GROUP BY region; Error: Wrong aggregate function (COUNT instead of SUM). ❌ INCORRECT (this is Clause-related): Original: SELECT region, SUM(sales) FROM data GROUP BY region; Modified: SELECT region, SUM(sales) FROM data; Error: Missing GROUP BY clause (this is clause-related, not function-related). Focus on changing HOW functions are used, not WHETHER they are used with proper clauses.

**Specific Error Type:** Math Functions
**Error Description:** The model misapplies mathematical functions (e.g., ROUND, CEIL, FLOOR), such as incorrect precision specifications or inappropriate numerical operations.

## ✅ Correct SQL Query
```sql
WITH median_income_diff_by_zipcode AS (
  WITH acs_2018 AS (
    SELECT
      "geo_id",
      "median_income" AS "median_income_2018"
    FROM
      CENSUS_BUREAU_ACS_2.CENSUS_BUREAU_ACS."ZIP_CODES_2018_5YR"
  ),
  acs_2015 AS (
    SELECT
      "geo_id",
      "median_income" AS "median_income_2015"
    FROM
      CENSUS_BUREAU_ACS_2.CENSUS_BUREAU_ACS."ZIP_CODES_2015_5YR"
  ),
  acs_diff AS (
    SELECT
      a18."geo_id",
      (a18."median_income_2018" - a15."median_income_2015") AS "median_income_diff"
    FROM
      acs_2018 a18
    JOIN
      acs_2015 a15 ON a18."geo_id" = a15."geo_id"
  )
  SELECT
    "geo_id",
    AVG("median_income_diff") AS "avg_median_income_diff"
  FROM
    acs_diff
  WHERE
    "median_income_diff" IS NOT NULL
  GROUP BY "geo_id"
),
base_census AS (
  SELECT
    geo."state_name",
    AVG(i."avg_median_income_diff") AS "avg_median_income_diff",
    AVG(
      "employed_wholesale_trade" * 0.38423645320197042 +
      "occupation_natural_resources_construction_maintenance" * 0.48071410777129553 +
      "employed_arts_entertainment_recreation_accommodation_food" * 0.89455676291236841 +
      "employed_information" * 0.31315240083507306 +
      "employed_retail_trade" * 0.51
    ) AS "avg_vulnerable"
  FROM
    CENSUS_BUREAU_ACS_2.CENSUS_BUREAU_ACS."ZIP_CODES_2017_5YR" AS census
  JOIN
    median_income_diff_by_zipcode i ON CAST(census."geo_id" AS STRING) = i."geo_id"
  JOIN
    CENSUS_BUREAU_ACS_2.GEO_US_BOUNDARIES."ZIP_CODES" geo ON census."geo_id" = geo."zip_code"
  GROUP BY geo."state_name"
)

SELECT 
  "state_name",
  "avg_median_income_diff",
  "avg_vulnerable"
FROM 
  base_census
ORDER BY 
  "avg_median_income_diff" DESC
LIMIT 5;
```
