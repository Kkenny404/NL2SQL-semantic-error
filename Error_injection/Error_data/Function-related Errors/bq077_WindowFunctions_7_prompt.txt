## 📋 Error Specification
**Error Category:** Function-related Errors
**Category Description:** Function-related Errors occur when NL2SQL models fail to correctly use SQL functions or misunderstand their purposes. We consider the following cases. CRITICAL: Function-related Errors focus on MISUSING the functions themselves, NOT on missing or incorrect clauses. Do not confuse with Clause-related Errors. Function-related Errors (CORRECT focus): Using wrong function types: SUM() instead of COUNT(), MAX() instead of MIN(); Incorrect function parameters: ROUND(value, -1) instead of ROUND(value, 2); Wrong function arguments: SUBSTR(text, 0, 5) instead of SUBSTR(text, 1, 5); Inappropriate function application: UPPER() on numeric data, mathematical functions on text; Function syntax errors: CAST(value, INT) instead of CAST(value AS INT). Clause-related Errors (AVOID - this is a different error category): Missing GROUP BY, ORDER BY, or HAVING clauses; Incorrect clause positioning or structure; Omitting necessary clauses that work with functions. Examples: ✅ CORRECT Function-related Error: Original: SELECT region, SUM(sales) FROM data GROUP BY region; Modified: SELECT region, COUNT(sales) FROM data GROUP BY region; Error: Wrong aggregate function (COUNT instead of SUM). ❌ INCORRECT (this is Clause-related): Original: SELECT region, SUM(sales) FROM data GROUP BY region; Modified: SELECT region, SUM(sales) FROM data; Error: Missing GROUP BY clause (this is clause-related, not function-related). Focus on changing HOW functions are used, not WHETHER they are used with proper clauses.

**Specific Error Type:** Window Functions
**Error Description:** The model misuses window functions (e.g., OVER, PARTITION BY), often failing to properly specify window frames or partition criteria.

## ❓ Natural Language Question
"For each year from 2010 to 2016, what is the highest number of motor thefts in one month?"

## ✅ Correct SQL Query
```sql
SELECT
  year,
  incidents
FROM (
  SELECT
    year,
    EXTRACT(MONTH
    FROM
      date) AS month,
    COUNT(1) AS incidents,
    RANK() OVER (PARTITION BY year ORDER BY COUNT(1) DESC) AS ranking
  FROM
    `bigquery-public-data.chicago_crime.crime`
  WHERE
    primary_type = 'MOTOR VEHICLE THEFT'
    AND year BETWEEN 2010 AND 2016
  GROUP BY
    year,
    month )
WHERE
  ranking = 1
ORDER BY
  year ASC
```
