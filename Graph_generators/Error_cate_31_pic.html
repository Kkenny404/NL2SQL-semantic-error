A Taxonomy of NL2SQL Translation Semantic Errors

Attribute-related Errors

Incorrectly mapping required columns in natural language queries to corresponding database attributes.

Attribute Mismatch
Selecting incorrect attributes from schema. The attribute [A] may be wrong.
Attribute Redundancy
Including unnecessary attributes not mentioned in NL. The attribute [A] may not be mentioned.
Attribute Missing
Failing to include essential attributes. The attribute [A] may be missing.

Table-related Errors

Failing to correctly identify, link, or utilize required tables from database schema.

Table Mismatch
Selecting incorrect tables. The table [T] may be wrong.
Table Redundancy
Including unnecessary tables. The table [T] may be unnecessary.
Table Missing
Failing to include required tables. The table [T] may be missing.
Join Condition Mismatch
Errors in JOIN conditions between tables. Join condition between [T] and [T] is incorrect.
Join Type Mismatch
Inappropriate JOIN types. The join type [K] is inconsistent with NL.

Value-related Errors

Incorrectly parsing or interpreting required attribute values from natural language expressions.

Value Mismatch
Failing to map values from NL to database representations. Value [V] in condition [C] may be wrong.
Data Format Mismatch
Improperly formatting values according to data type. Data format of [V] in [A] may be wrong.

Operator-related Errors

Failing to select appropriate operators for SQL conditions.

Comparison Operator
Incorrect comparison operators (e.g., using '>' instead of '>='). Operator [O] in condition [C] may be wrong.
Logical Operator
Misinterpreting logical relationships (AND, OR, NOT). Boolean operator [O] or precedence may be wrong.

Condition-related Errors

Failing to properly handle query conditions, both explicit and implicit.

Explicit Condition Missing
Missing stated conditions. Condition [C] in NL may be missing.
Explicit Condition Mismatch
Incorrect conditions deviating from NL. Condition [C] may be wrong.
Explicit Condition Redundancy
Unnecessary conditions not in NL. Condition [C] not mentioned in NL.
Implicit Condition Missing
Missing implied conditions (e.g., NULL handling). Missing implicit conditions [C] (e.g., IS NOT NULL).

Function-related Errors

Incorrectly using SQL functions or misunderstanding their purposes.

Aggregate Functions
Incorrect aggregate functions [F] (e.g., SUM, AVG).
Window Functions
Incorrect window functions [F] (e.g., OVER, PARTITION BY).
Date/Time Functions
Incorrect date/time functions [F] (e.g., STRFTIME).
Conversion Functions
Incorrect conversion functions [F] (e.g., CAST).
Math Functions
Incorrect math functions [F] (e.g., ROUND).
String Functions
Incorrect string functions [F] (e.g., SUBSTR).
Conditional Functions
Incorrect conditional functions [F] (e.g., CASE WHEN).

Clause-related Errors

Failing to correctly include, omit, or structure SQL clauses.

Clause Missing
Missing necessary clauses. Clause [K] (e.g., GROUP BY) is missing.
Clause Redundancy
Including extraneous clauses. Clause [K] (e.g., GROUP BY) is redundant.

Subquery-related Errors

Failing to correctly use or generate subqueries.

Subquery Missing
Missing necessary subquery. Subquery [Q] is missing.
Subquery Mismatch
Subquery doesn't match context. Subquery [Q] mismatches with NL logic.
Partial Query
Query is only part of complete query. Query [Q] is partial.

Other Errors

Incorrect use of special keywords and queries with significant semantic deviation.

ASC/DESC
Improper handling of result ordering. ASC/DESC usage is incorrect.
DISTINCT
Improper deduplication operations. DISTINCT is omitted or incorrectly applied.
Other
SQL deviates significantly from required output, necessitating complete rewrite.
